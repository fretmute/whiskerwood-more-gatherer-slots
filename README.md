# More Gatherer Slots
A mod for adding additional worker slots to gathering structures.

## Overview
- Provides the ability to add one or two more slots two each of the gathering structures:
  - Gathering Hut
  - Farm
  - Mining Camp
  - Woodcutters Camp
- Each slot can be configured for one of three required skill levels:
  - None
  - Apprentice
  - Craftsmaster
- The final slot can be configured to apply a bonus to the camp if it is filled.

## Settings
- Note that all settings require a restart to change. The fixes are applied immediately when the game starts.
- The mod defaults to disabled. Set your configuration when you install the mod and then restart the game.

## Known Issues
- If you remove a worker slot that has been filled, you must go into the worker overview page to "free" the orphaned worker.
- There may be other oddness about removing slots once a game has been saved. Edit with care.
